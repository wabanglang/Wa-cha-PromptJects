# Private Field Rules

Private fields are fields that should not be auto-filled, guessed, or entered into a public computer unless the applicant knowingly chooses to do so or the official system requires it.

## Private human-only fields

- Legal name
- Date of birth
- Social Security number
- Signature
- Phone number
- Email
- Current safe location
- Immigration or citizenship status
- Medical diagnosis
- Disability documentation
- Criminal/legal history
- Domestic violence or trafficking disclosure
- Bank or account number
- Case number
- Benefit card number
- Security question answer
- Mother’s maiden name
- Emergency contact
- Prior names or aliases
- Veteran discharge information

## Rule

Leave private fields blank in the public worksheet unless the applicant personally fills them out on paper or with a trusted authorized advocate.

## Marker

Use this label on worksheets:

```text
PRIVATE — FILL OUT ONLY ON PAPER OR WITH TRUSTED ADVOCATE
```
