# Wa-cha PromptJects

**Free public promptjects for community social aid, universal access, and low-cognitive-load help.**

Wa-cha PromptJects is a public repository for reusable prompts, worksheets, field maps, and plain-language automation aids that help people navigate social-service paperwork more safely and honestly.

The first corpus focuses on reducing the burden of long benefit-application packets by separating:

- private human-only fields,
- generic profile-based answers,
- advocate-review fields,
- skip logic,
- printable worksheets,
- electronic entry maps,
- validation checks.

## Start here

For nontechnical users:

1. Open `START_HERE.md`.
2. Pick a promptject from `PROMPTJECT_INDEX.md`.
3. Print or copy the worksheet/prompt.
4. Fill private identity details only on paper or with a trusted advocate.
5. Review before any official submission.

## Safety boundary

This repository is not a government agency, legal advisor, benefits eligibility authority, or medical provider. It provides completion aids. Applicants and advocates must review all answers before submission. Do not invent facts, fabricate eligibility, or submit false information.
