# Start Here — 0-Tech Use

This repository is designed for people who do not code.

## What this is

A promptject is a ready-to-use package that can contain:

- a prompt,
- a printable worksheet,
- a checklist,
- a form-field map,
- an example,
- a validation rule,
- plain-language instructions.

## Fastest use

1. Open `PROMPTJECT_INDEX.md`.
2. Choose a promptject.
3. Open its prompt or worksheet.
4. Print the worksheet or copy the prompt into your AI tool.
5. Fill out private information only on paper or with a trusted advocate.

## Privacy rule

Do not type sensitive identity details into a public computer unless absolutely necessary.

Sensitive details include:

- Social Security number,
- date of birth,
- legal name,
- immigration or citizenship status,
- medical diagnosis,
- disability documentation,
- criminal/legal history,
- domestic violence or trafficking information,
- security questions,
- mother’s maiden name,
- bank/account numbers,
- safe location,
- signature.

## Honesty rule

Use these tools to reduce burden, not to fabricate eligibility. Every submitted answer must be true.
