# Compact Execution Prompt

Compress the supplied social-service form packet into a short, printable, privacy-preserving worksheet.

Extract every required, optional, conditional, sensitive, and skippable field. Merge duplicates. Preserve official meaning.

Use this default profile only where it truthfully applies:

```text
single adult male, homeless/no fixed address, no spouse, no children, no dependents, no job, no income, no money, no cash, no bank account, no assets, no property, no real estate, no vehicle, race/ethnicity declined where allowed.
```

Separate all fields into:

1. Private human-only fields.
2. Profile-based auto-fill fields.
3. Advocate-review fields.
4. Optional/skippable fields.
5. Electronic-entry mapping fields.

Never invent personal facts. Do not auto-answer legal name, DOB, SSN, citizenship/immigration, medical, disability, veteran, criminal/legal, domestic violence, trafficking, security-question, mother’s-maiden-name, bank/account, signature, or safe-location fields.

Produce:

A. printable short-form worksheet with highlighted blanks and examples;  
B. generic auto-fill answer bank;  
C. advocate-review checklist;  
D. skip-logic table;  
E. official-form electronic entry map;  
F. document checklist;  
G. contradiction/error review table;  
H. final signing checklist.

Use low-cognitive-load design: plain language, one question per line, grouped sections, large blanks, examples, consistent yes/no wording, no dense paragraphs, no unnecessary legal jargon.

Mark fields as:

- `[FILL IN]` for applicant,
- `[AUTO]` for profile answer,
- `[REVIEW]` for advocate review,
- `[SKIP]` for not applicable.

Final output must help a person complete the paper worksheet privately, then allow a trusted certified advocate to enter the official application electronically with minimal repeated questioning.
