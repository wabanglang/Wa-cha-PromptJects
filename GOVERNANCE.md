# Governance

## Project purpose

Wa-cha PromptJects exists to reduce paperwork burden, increase applicant safety, and help advocates complete social-aid workflows honestly.

## Core standard

A promptject is acceptable when it is:

- useful,
- honest,
- privacy-preserving,
- low-cognitive-load,
- non-predatory,
- accessible to nontechnical users,
- clear about what must be verified.

## Prohibited direction

This project should not become a tool for fraud, coercive data collection, dark-pattern enrollment, exploitative gatekeeping, or false official representation.
